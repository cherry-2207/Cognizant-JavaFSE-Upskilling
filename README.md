# Cognizant Java FSE Upskilling

This repository contains hands-on exercises completed for the **Cognizant Java Full Stack Engineer (FSE) Upskilling Program**.

## Topics Covered


- HTML5, CSS3, Bootstrap 5, and JavaScript for frontend development
- MySQL query writing and database problem solving
- Core Java programming, OOP, collections, files, JDBC, modules, networking, reflection, and concurrency

## Repository Structure

```text
Cognizant-JavaFSE-Upskilling/
├── Module-1_HTML5/
├── Module-1_CSS3/
├── Module-1_Bootstrap/
├── Module-1_JavaScript/
├── Module-2_MySQL/
├── Module-3_Core-Java/
```

## Download Steps

### Option 1: Download ZIP

1. Open the GitHub repository page.
2. Click **Code**.
3. Select **Download ZIP**.
4. Extract the ZIP file.
5. Open the extracted folder in VS Code or your preferred IDE.

### Option 2: Clone with Git

```bash
git clone <repository-url>
cd Cognizant-JavaFSE-Upskilling
```

Replace `<repository-url>` with the actual GitHub repository URL.

## How to Run

### HTML, CSS, Bootstrap, and JavaScript

Open the related `index.html` file in a browser:

```text
Module-1_HTML5/index.html
Module-1_CSS3/index.html
Module-1_Bootstrap/index.html
Module-1_JavaScript/index.html
```



Then open:

```text
http://localhost:5501/index.html
```

### MySQL

Open the SQL files in `Module-2_MySQL/` and run them in MySQL Workbench or another MySQL CLI:

- `schema.sql`
- `data.sql`
- `queries.sql`

### Core Java

Compile and run individual Java programs from `Module-3_Core-Java/`:

```bash
cd Module-3_Core-Java
javac file_name.java
java file_name
```

For exercises that use JDBC, add the required database driver to the classpath before running.
